# Laboratorios Fundamentos de Internet de las Cosas 
Repositorio de los códigos (`.ino`) de los laboratorios de la asignatura **Fundamentos de Internet de las Cosas 351G8F**. Los laboratorios cubren instrumentación, acondicionamiento de señal, lazos de control (ON-OFF, PI, PD, PID), supervisión tipo SCADA y comunicación industrial/IoT, todos implementados sobre un ESP32.
